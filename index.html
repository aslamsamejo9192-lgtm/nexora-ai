Gemini runs on this site's own server key — you don't need to paste anything. Just close this and start chatting.

OpenAI API keys are not free — they need a paid OpenAI platform account with billing / credits. A ChatGPT Plus subscription does not include API credits. Image generation (GPT-Image-1 / DALL·E) is charged per image on top of chat.

  1. Open OpenAI Platform — API keys and sign in.
  2. Click Create new secret key and copy it right away — OpenAI shows it only once. Keys start with sk-.
  3. Make sure billing or credits are set up under Platform billing, then paste the key below and press Connect.

OpenRouter gives you one key for many models — including Llama. Models marked :free (like Llama 3.3 70B :free) cost nothing and need no card — they are limited (about 50 requests/day on a free account, and the free model list can change). Paid models are charged per use from your OpenRouter credit; a small top-up is only needed if you want more than the free limit.

  1. Open OpenRouter — API keys and sign in (or create a free account).
  2. Click Create Key, name it, and copy the key. Keys start with sk-or-.
  3. Paste it below and press Connect — no top-up is needed to start with the :free models.

Gemini needs no key from you — your messages reach Google's Gemini API through this site's server. ChatGPT and OpenRouter keys are kept only in this tab's memory, sent only to OpenAI and OpenRouter. Reload the page and you'll paste those again; they are never uploaded anywhere else.
